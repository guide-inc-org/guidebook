# セルフアップデート

CLI から直接 guidebook を最新バージョンに更新します。

## 使い方

```bash
guidebook update
```

GitHub から最新リリースをダウンロードし、現在のバイナリを置き換えます。

## 仕組み

1. GitHub で最新リリースを確認
2. 現在のバージョンと比較
3. プラットフォーム（macOS、Linux、Windows）に適したバイナリをダウンロード
4. SHA256 チェックサムを検証（リリースに含まれている場合）
5. 現在のバイナリを置き換え

## プラットフォーム対応

| プラットフォーム | アーカイブ形式 |
|----------------|--------------|
| macOS (Intel/ARM) | `.tar.gz` |
| Linux | `.tar.gz` |
| Windows | `.zip` |
