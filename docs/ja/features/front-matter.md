# フロントマター

Markdown ファイルに YAML フロントマターを追加してページレベルのメタデータを設定します。

## 構文

```markdown
---
title: カスタムページタイトル
description: このページの簡単な説明
---

# ページコンテンツ

ここにコンテンツを記述。
```

## サポートされるフィールド

| フィールド | 説明 |
|-----------|------|
| `title` | ページタイトルを上書き（`<title>` とナビゲーションに使用） |
| `description` | ページの説明（`<meta>` タグに使用） |

## 動作

- フロントマターはレンダリング出力から除去されます
- `title` が設定されている場合、ファイル内の最初の `# 見出し` を上書きします
- 空のフロントマター（`---\n---`）は有効で単に無視されます
- 無効な YAML は黙って無視されます（ページは正常にレンダリング）
