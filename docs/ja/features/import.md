# ファイルインポート

`@import` ディレクティブで他のファイルの内容を取り込みます。

## 構文

```html
<!-- @import("path/to/file.md") -->
```

ビルド時に、ディレクティブは参照先ファイルの内容に置換されます。

## 例

共通ヘッダーをインクルード：

```html
<!-- @import("shared/header.md") -->
```

コードファイルをインクルード：

```html
<!-- @import("examples/config.json") -->
```

## 再帰インポート

インポートされたファイルにも `@import` を含めることができます。guidebook は再帰的に処理し、循環インポートを検出してループを防止します。

## パス解決

パスは `@import` ディレクティブを含むファイルからの相対パスです。
