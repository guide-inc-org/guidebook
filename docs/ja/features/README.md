# 機能

guidebook には多くの組み込み機能があります：

- [Mermaid 図](mermaid.md) - コードで図を作成
- [折りたたみチャプター](collapsible.md) - 展開可能なサイドバー
- [検索](search.md) - 全文検索
- [多言語対応](multi-language.md) - 複数言語でブックを作成
- [用語集](glossary.md) - 自動リンクされる用語定義とツールチップ
- [ファイルインポート](import.md) - 他のファイルの内容を取り込み
- [フロントマター](front-matter.md) - ページの YAML メタデータ
- [テンプレート](templates.md) - Nunjucks/Jinja2 の条件分岐、ループ、フィルター
- [AsciiDoc](asciidoc.md) - Markdown と併用して `.adoc` ファイルを使用
- [数式（KaTeX）](math.md) - 数学の公式をレンダリング
- [SVG 処理](svg.md) - SVG の外部化またはインライン化
- [OpenAPI / Swagger](openapi.md) - スペックから Swagger UI を生成
- [セルフアップデート](self-update.md) - CLI からのアップデート
